# 正则表达式可视化调试器

NFA 状态机可视化、逐步匹配高亮、分组捕获标注、回溯追踪的交互式正则调试工具。

## 技术栈

- Vue 3 + TypeScript + Vite
- Pinia 状态管理
- Tailwind CSS 样式
- Canvas 2D 状态机渲染

## 功能

- 正则表达式 NFA 状态机 Canvas 可视化
- 逐步匹配高亮（字符→状态→转移边）
- 分组捕获实时标注与颜色编码
- 回溯路径追踪与步骤计数
- 20+ 常用模式模板库
- 正则语法树分层可视化
- 匹配性能统计（步骤数/回溯次数/耗时）
- 反向引用/零宽断言/贪婪惰性模式支持
- 测试用例历史：保存当前正则、测试文本与关注步骤，最近用例按时间倒序重新打开
- 会话恢复：刷新/重新进入自动恢复最后一次会话（高亮、播放位置、统计与保存时一致）
- 异常处理：保存失败/空历史/重复保存/已删除用例均有明确提示，编辑内容不丢失

## 启动

```bash
cd frontend
npm install
npm run dev
```
